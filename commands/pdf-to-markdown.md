# 目标

执行一次完整的 PDF 转 Markdown 流程。

## 输入

- 必填输入：PDF 路径
- 选填输入：输出 Markdown 路径
- 缺失时降级动作：提示用户提供 PDF 路径

## 执行步骤

1. 读取 `SKILL.md` 与 `rules/route-and-env.md`。
2. 判断当前 PDF 属于简单文本型、复杂版式型还是扫描型。
3. 如果是扫描型，提示需要 OCR，停止执行。
4. 如果是简单文本型：
   - 检查 `markitdown`
   - 缺失时再安装
   - 执行 `markitdown`
5. 如果是复杂版式型：
   - 检查 `PyMuPDF`
   - 缺失时安装到 `.\_pydeps`
   - 生成临时 Python 脚本
   - 执行转换
   - 删除临时脚本
6. 抽查输出结果。
7. 如果结果基本可用，只列出剩余少量问题区域。

## 输出

- 主输出：同名或用户指定名称的 Markdown 文件
- 补充输出：若存在问题，仅列出剩余问题区域
